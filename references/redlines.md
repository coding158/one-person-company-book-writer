# 红线与出处

每条都写明依据。平台规则会变，上架前以平台当时的页面为准。

| 红线 | 依据 | 脚本怎么查 |
|---|---|---|
| 秘密不入稿 | 通用安全惯例：密钥、令牌、私钥不进任何会公开的文本 | 10 类常见密钥特征（写在 `check_book.py` 里） |
| 不写邮箱、手机号等个人联系方式 | 隐私惯例 | 正则 |
| 未获授权的第三方图像不放（图版、照片、裁片、描摹图及其他第三方材料） | 版权惯例 | 插图、「图版」字样都报 WARN，由人判断 |
| 不以免费书、赠品换评论 | Amazon 客户评论政策（NOT VERIFIED，以当时的政策页为准） | 正则，ERROR |
| 不承诺疗效 | 健康类内容的通用红线 | 正则，ERROR |
| 收入、销量数字要有出处 | 教程里流传的收入、BSR 换算数字多数无法核实 | 正则，WARN |
| 进 KDP Select 的书，站外公开不超过 10% | KDP Select 条款与帮助页（两处口径可能不同，上架前复核） | `--public` 给出站外文本，按 8 字片段算重合比例 |
| KDP 不收简体中文；繁体只出电子书 | KDP 帮助页 G200673300（以当时页面为准） | 上架语言为 zh-Hans 报 ERROR |
| AI 生成须披露，AI 辅助不必 | KDP 帮助页 G200672390（以当时页面为准） | `kdp_metadata.py` 要求三项都填 |
| 上架、定价、Select、打样由作者本人操作 | 账号安全：AI 不代登录出版平台 | 不自动查，流程关口 |

## 站外公开的文本

如果书的部分内容已经发在别处（博客、社交平台），而书又要进 KDP Select：
把发出的文本存进书稿项目的 `public/`，并写进 `book-config.json` 的 `public_sources`。之后每次 `check_book.py` 都会算重合比例。
